FORGE runs coding agents against a plan, checks what they built, and picks up where they left off.

- [START.md](docs/START.md) gets a project running.
- [ARCHITECTURE.md](docs/ARCHITECTURE.md) explains the runner and how it resumes.
- [OBSERVATORY.md](docs/OBSERVATORY.md) shows how to follow a run locally.
- [UI_UX.md](docs/UI_UX.md) is the design and handoff guide.
- [LEARNING.md](docs/LEARNING.md) explains how to reuse a lesson from a build.
- [TESTS.md](docs/TESTS.md) covers the checks, simulations and their limits.
- [AGENTS.md](AGENTS.md) tells coding agents how to work on this repo.
